# Digital HR

Прототип единого HR-портала Jana Group для хакатона Jańa Post: профиль, заявки, Jana Academy, ассистент Al Jana и уведомления.

## Запуск

Нужны Node.js 22 и npm.

```bash
npm install
npm run dev
```

Портал: http://localhost:3000

Без переменных окружения данные живут в памяти процесса и заполняются демо-набором. Шаблон опций: `.env.example`.

```bash
npm test
npm run typecheck
npm run build && npm start
```

## Docker

MongoDB сохраняет демо-данные между перезапусками.

```bash
docker compose up --build
```

Портал: http://localhost:3000

## Язык

В шапке портала и на экране входа переключатель **RU / KZ**. Выбор пишется в cookie `hr-locale`. Интерфейс, подписи статусов, даты и заголовки уведомлений переключаются. Тексты курсов и ответы базы знаний Al Jana остаются на языке материалов (вопросы-подсказки ассистента на русском, чтобы совпасть с базой).

## Сценарии

1. Вход сотрудником: профиль, заявки, обучение, уведомления.
2. Заявка на отпуск или аванс и смена статуса. Руководитель согласует в «Согласованиях».
3. Daniyar не видит заявки и карточку Alikhan. Madina видит только маркетинг. HR видит компанию и не может согласовать свою заявку.
4. Jana Academy: материал, прогресс, тест.
5. Al Jana отвечает по базе знаний и показывает источник.
6. Вопрос вне базы не выдумывается: ассистент предлагает передать его в HR. Ответ HR приходит уведомлением.

## Что сделано, что смоделировано

Полностью в прототипе: роли и серверные права, кабинет, отпуск и аванс с историей, академия, Al Jana с источником и эскалацией, уведомления, переключение RU/KZ.

Смоделировано: вход без корпоративного IdP, `1С:ЗУП` и `Documentolog` через порты в `lib/server/integrations` (реализации-заглушки). Официальные кадровые поля только для чтения.

Дальше: живые интеграции, электронная подпись, рекрутинг и performance management в этот прототип не входят.
