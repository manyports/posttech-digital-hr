# Digital HR

Прототип единого HR-портала Jana Group для хакатона Jańa Post: профиль, заявки, Jana Academy, ассистент Al Jana и уведомления.

## Запуск

Нужны Node.js 22 и npm.

```bash
npm install
npm run dev
```

Портал: http://localhost:3000

Схема: [docs/architecture.svg](docs/architecture.svg). Презентация: [docs/Digital-HR.pptx](docs/Digital-HR.pptx). Точки обмена с `1С:ЗУП` и `Documentolog` вынесены в отдельные адаптеры; в демонстрационном режиме они возвращают тестовые ссылки и статусы.

Без переменных окружения данные живут в памяти процесса и заполняются демо-набором. Шаблон опций: `.env.example`.

```bash
npm test
npm run test:mongo   # тот же набор тестов на настоящей MongoDB (бинарник скачивается один раз)
npm run typecheck
npm run build && npm start
```

## Docker

MongoDB сохраняет демо-данные между перезапусками.

```bash
docker compose up --build
```

Портал: http://localhost:3000

## Vercel

Нужны `MONGODB_URI` и `MONGODB_DB` в настройках проекта. Функции закреплены в регионе базы (`vercel.json` → `regions`): сейчас Sydney (`syd1`) под кластер Atlas в `ap-southeast-2`. Если кластер переезжает, регион меняется вместе с ним (Frankfurt → `fra1`).

## Язык

В шапке портала и на экране входа переключатель **RU / KZ**. Выбор пишется в cookie `hr-locale`. Интерфейс, подписи статусов, даты и заголовки уведомлений переключаются. Тексты курсов и ответы базы знаний Al Jana остаются на языке материалов (вопросы-подсказки ассистента на русском, чтобы совпасть с базой).

## Сценарии

1. Вход сотрудником: профиль, заявки, обучение, уведомления.
2. Заявка на отпуск или аванс: сотрудник может сохранить черновик или сразу отправить его. Руководитель согласует отправленную заявку в «Согласованиях».
3. Daniyar не видит заявки и карточку Alikhan. Madina видит только своё отделение. HR видит компанию и не может согласовать свою заявку.
4. Jana Academy: материал, прогресс, тест.
5. Al Jana отвечает по базе знаний и показывает источник.
6. Вопрос вне базы не выдумывается: ассистент предлагает передать его в HR. Ответ HR приходит уведомлением.

## Что сделано, что смоделировано

Полностью в прототипе: роли и серверные права, кабинет, отпуск и аванс с историей, академия, Al Jana с источником и эскалацией, уведомления, переключение RU/KZ.

В демонстрационном режиме работают вход без корпоративного IdP и тестовые адаптеры `1С:ЗУП` и `Documentolog` через порты в `lib/server/integrations`. Официальные кадровые поля доступны только для чтения.

Дальше: живые интеграции, электронная подпись, рекрутинг и performance management в этот прототип не входят.
